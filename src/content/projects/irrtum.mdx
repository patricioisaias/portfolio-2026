## Interfaz de usuario

IRRTUM es un procesador de audio gratuito desarrollado en Pure Data, diseñado para la creación y exploración de texturas sonoras, glitches y procesamiento experimental de audio.

El instrumento permite manipular diferentes parámetros de forma independiente y aleatorizarlos para generar variaciones sonoras impredecibles. Su interfaz incorpora herramientas de sampler y looper, cadenas de efectos, una matriz de modulación y un sistema de aleatorización que amplía las posibilidades de experimentación y diseño sonoro.

IRRTUM puede ejecutarse en Pure Data Vanilla 0.54, utilizando las librerías Cyclone, ELSE y Freeverb~, o mediante [plugdata](https://plugdata.org/), que incorpora estas librerías de forma integrada.

El proyecto explora la relación entre programación, síntesis y experimentación sonora, convirtiendo el procesamiento de audio en una herramienta para la creación de paisajes y texturas sonoras.
